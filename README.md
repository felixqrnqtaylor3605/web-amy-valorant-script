## What it does

Web Amy Valorant is a browser-first utility made to reduce repetitive in-game actions and surface helpful visual cues while you play. Because it is built with HTML and JavaScript, it stays on the client side and avoids extra installs, bundled tools, or setup overhead. The focus is on a simple collection of automation helpers that can be turned on quickly, so players can spend more attention on decision-making instead of routine input.

This release is aligned with the current Valorant season and includes updates intended to keep pace with recent game changes. Since it runs from the web, it is usable across operating systems wherever a modern browser is available. If you want a lightweight practice aid or a utility for everyday actions, Web Amy Valorant aims to provide a clean and direct experience.

## FAQ

**How do I install the script?**  
Download the HTML file and open it in your browser. That is all it takes.

**Will this work after a Valorant update?**  
The goal is to keep compatibility aligned with each major patch. Check the repository for the latest updates.

**Can I customize the hotkeys?**  
Yes. Hotkeys can be adjusted directly in the script's settings panel.

**Is this safe to use alongside Valorant?**  
The script runs only in your browser and does not change game files. Use it at your own discretion and in line with Riot Games' terms of service.

**Where are my settings saved?**  
Settings are kept locally in your browser's localStorage and remain available between sessions.
